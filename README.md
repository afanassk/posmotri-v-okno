## 📖 Описание проекта

**«Посмотри в окно»** — это верстка интерфейса интерактивного веб-сервиса, позволяющего виртуально «выглянуть» из окон разных городов мира. В рамках проекта реализованы сложный макет страницы с видеоплеером, карточки видов, система фильтрации и кастомные элементы форм.

### 📌 Цели и задачи проекта

- Верстка комплексной страницы по Figma-макету с сочетанием медиаконтента и элементов управления.
- Создание доступных и стилизованных кастомных форм (инпуты, чекбоксы, радиокнопки).
- Построение гибких и адаптивных сеток с помощью CSS Grid и Flexbox.
- Отработка продвинутых CSS-селекторов и состояний доступности (focus-visible).
- Верстка состояния загрузки (локальные прелоадеры) для элементов интерфейса.

### 🛠️ Стек технологий

- **HTML5** (семантическая разметка, форма поиска и элементы управления)
- **CSS3** (Flexbox, CSS Grid, кастомный скроллбар, анимация прелоадеров)
- **БЭМ (BEM)** — методология структурирования и именования классов
- **Pixel Perfect** — для проверки верстки

## 💡 Выводы по результатам проекта

- **Кастомные элементы форм:** Освоила работу с кастомными формами (чекбоксы, инпуты) с использованием appearance: none и псевдоэлементов (::before, ::after).
- **Комбинированные раскладки:** Научилась эффектно комбинировать Flexbox и CSS Grid для построения сложных и гибких лейаутов.
- **Современные CSS-селекторы:** Отработала приём :has(:focus-visible) для гибкого управления состояниями родительских контейнеров при фокусе с клавиатуры.
- **Локальное позиционирование элементов:** Научилась позиционировать прелоадеры локально внутри конкретных блоков, а не глобально на весь экран.
- **Доступность (Accessibility):** Закрепила использование паттерна .visually-hidden для корректного и доступного скрытия системных элементов управления без потери удобства для ассистивных технологий (screen readers).

## ⚙️ Инструкция по развертыванию и системные требования

### Системные требования

Для запуска проекта достаточно любого современного браузера:

- Google Chrome / Яндекс Браузер
- Mozilla Firefox
- Apple Safari
- Microsoft Edge

### Инструкция по локальному запуску

1. Клонируйте репозиторий на свой ПК:

```bash
git clone git@github.com:afanassk/posmotri-v-okno.git
```

2. Перейдите в директорию проекта:

```bash
posmotri-v-okno
```

3. Откройте файл `index.html` в браузере.
